# 🌍 Global Import & Export Trade Analysis
> **An interactive data analytics dashboard for exploring global trade patterns, trends, and insights.**

## 📊 About the Project
This project analyzes **global import and export data** to uncover country-wise trade performance, growth trends, product shares, and tariff patterns.
Built with **Python, Pandas, Plotly, and Streamlit**, it transforms complex trade data into an interactive and easy-to-understand dashboard.

## ✨ Key Features
* 🌎 Country-wise Import & Export Analysis
* 📈 Trade Growth & Yearly Trends
* 🏆 Top Importing & Exporting Countries
* 📦 Product Share Analysis
* 💰 Tariff Analysis — MFN & AHS
* 🔎 Interactive Filters & Visualizations
* 📊 Data-driven Trade Insights

## 🛠️ Tech Stack
**Python • Pandas • Plotly • Streamlit • NumPy**

## 🚀 Run Locally
pip install -r requirements.txt
streamlit run stream.py

## 🎯 Goal
To turn global trade data into **meaningful visual insights** that can support better understanding of international trade and market trends.
